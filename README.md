# Атмосфера — Telegram Mini App

Онлайн RP-свидание на двоих. Пиксель-арт, мини-игры, интерактивные локации,
совместное видео и музыка. Работает как Telegram Mini App.

## Что уже готово

- 10 локаций с интерактивными предметами
- 6 мини-игр (Flappy-lips, такт, танец, рука, комплимент, искра)
- Кинотеатр: своё видео с телефона / YouTube / прямая ссылка (синхронно)
- Ночной клуб: свои треки (синхронно)
- ИИ «Атмосфера» (OpenRouter, ключ только у хоста)
- Мультиплеер через PeerJS

## ⚠️ Для Telegram Mini App нужен HTTPS

Telegram не открывает Mini App по `http://localhost`. Нужен публичный HTTPS.
Два варианта — выбери один:

### Вариант A: GitHub Pages (бесплатно, навсегда)

Деплой статических файлов на GitHub Pages. Никакой `npm start` не нужен —
всё работает в браузере (AI — прямо из браузера, мультиплеер — PeerJS).
Ссылка навсегда останется одной и той же.

1. Создай репозиторий `atmosfera` на github.com (Public).
2. Загрузи ВСЕ файлы из этой папки: `index.html`, `styles.css`, `src/`
   (целиком), `package.json`, `server.js`, `README.md`. Сохрани структуру.
3. `Settings` → `Pages` → Source: `Deploy from a branch` → Branch: `main` /
   `/ (root)` → Save.
4. Через минуту появится ссылка `https://твой-ник.github.io/atmosfera/`.

**Вставь эту ссылку в BotFather** (см. ниже).

### Вариант B: Cloudflare Tunnel из Termux (бесплатно, временная ссылка)

Каждый запуск даёт новую ссылку. Придётся обновлять её в BotFather.

```bash
pkg install cloudflared -y
# терминал 1:
cd ~/storage/downloads/date-sim && npm start
# терминал 2:
cloudflared tunnel --url http://localhost:8080
```

В выводе появится `https://xxxx-xxxx.trycloudflare.com` — это твой HTTPS URL.
Не закрывай оба терминала, пока играешь.

## Настройка в BotFather

Открой `@BotFather` в Telegram:

### Как Menu Button (кнопка внизу чата)

```
/setmenubutton
> выбери своего бота
> URL: https://твоя-ссылка
> Button text: Играть
```

Теперь у бота внизу чата синяя кнопка «Играть» — жмёшь, игра открывается.

### Или как отдельное Mini App (красивее)

```
/newapp
> выбери бота
> Title: Атмосфера
> Description: RP-свидание на двоих
> Photo: загрузи любую картинку 640×360
> GIF: пропусти
> Web App URL: https://твоя-ссылка
> Short name: atmosfera
```

Готово — ссылка `t.me/твой-бот/atmosfera`.

## Синхронизация startapp (глубокие ссылки)

Открой `src/game.js`, найди в начале:

```
var BOT_USERNAME = '';   // напр. 'atmosfera_bot' (без @)
var BOT_APPNAME  = '';   // если создавал через /newapp — короткое имя, напр. 'atmosfera'
```

Заполни под свой бот:

- Только `/setmenubutton` → `BOT_USERNAME = 'твой_бот'`, `BOT_APPNAME = ''`
- `/newapp` → `BOT_USERNAME = 'твой_бот'`, `BOT_APPNAME = 'atmosfera'`

Теперь кнопка **📤 Поделиться кодом** в лобби создаст ссылку
`t.me/твой_бот?startapp=ABCD` — друг откроет и код сам подставится.

Если не заполнишь — кнопка просто копирует код в буфер.

## Как играть

1. Хост: **Создать комнату** → 4-символьный код.
2. Жмёт **📤 Поделиться кодом** → отправляет другу.
3. Друг открывает ссылку → код уже в поле → **Войти**.
4. Хост: **Начать** → голосование за локацию.
5. По очереди пишете действия. Перед действием — мини-игра.
6. В кинотеатре хост может включить видео. В клубе — трек.

## Локальная разработка

```
npm start
```

Открой `http://localhost:8080` в браузере. Галочка «Мини-игры» в меню —
отключить мини-игры. `?startapp=ABCD` в URL эмулирует глубокую ссылку.

## Файлы

```

package.json    — конфиг
index.html      — все экраны + Telegram SDK
styles.css      — оформление

```

## Если что-то не работает

**Белый экран в Telegram**: сверху будет баннер — синий «Загрузка…» или
красный с текстом ошибки. Если красный — там написано что не так.

**Не открывается Mini App**: HTTPS не настроен или URL не тот. Проверь,
что ссылка в BotFather открывается в браузере (не только в Telegram).

**Мультиплеер не подключается**: оба игрока должны открыть ОДНУ И ТУ ЖЕ
ссылку. PeerJS-сигналинг идёт через `wss://0.peerjs.com` — иногда тормозит,
попробуйте перезайти.
